🚀 Workshop Hands-On Instructions

Follow these 6 steps to make your first open-source Pull Request and see your card appear live on this wall!

1

Fork and Clone the Repository

Click Fork at the top right of this GitHub repo to create your own copy, then clone it to your local machine:

git clone https://github.com/YOUR_USERNAME/DevPulse.git
cd DevPulse
2

Create a New Feature Branch

Never commit directly to main! Always create a descriptive branch for your changes:

git checkout -b feature/add-YOUR_USERNAME
3

Create Your Profile JSON File

Copy data/students/_template.json to a new file named data/students/YOUR_USERNAME.json and fill in your details, avatar, and custom RPG stats!

cp data/students/_template.json data/students/YOUR_USERNAME.json
4

Register Your File (For Local Testing)

Open data/registry.json and add your filename (e.g. "YOUR_USERNAME.json") to the list. Double check your JSON syntax (commas and quotes)!

5

Commit and Push Your Branch

Stage your changes, create an informative commit message, and push your branch to GitHub:

git status
git add data/students/YOUR_USERNAME.json data/registry.json
git commit -m "feat: add profile card for YOUR_USERNAME"
git push -u origin feature/add-YOUR_USERNAME
6

Open a Pull Request! 🎉

Go to the original GitHub repository. GitHub will show a banner saying "feature/add-YOUR_USERNAME had recent pushes". Click Compare & pull request, write a brief description, and submit! Once the instructor or peer merges it, your card is officially in the Hall of Fame!
