Contribution Guide

Complete these 6 steps to submit your first open-source Pull Request and add your card to the roster.

1

Fork and Clone Issue #07

Fork the repository to your personal GitHub account, then clone it to your local environment:

git clone https://github.com/Akhilesh-pujar/GitHub_workshop
cd DevPulse
2

Create a Feature Branch

Avoid committing to the main branch. Create a descriptive feature branch:

git checkout -b feature/add-YOUR_USERNAME
3

Create Your Profile

Copy data/students/_template.json to data/students/YOUR_USERNAME.json and populate your information:

cp data/students/_template.json data/students/YOUR_USERNAME.json
4

Register Your File

Add your filename (e.g., "YOUR_USERNAME.json") to data/registry.json for local verification.

5

Stage, Commit & Push

Review modified files, commit with a standard conventional commit message, and push upstream:

git status
git add data/students/YOUR_USERNAME.json data/registry.json
git commit -m "feat: add profile for YOUR_USERNAME"
git push -u origin feature/add-YOUR_USERNAME
6

Open a Pull Request

Navigate to the upstream repository on GitHub, select Compare & pull request, provide a summary of your changes, and submit for peer review.

Workshop Engineering QA Backlog

Sprint 1 Pre-Release Defect Register • MTech Hands-on Track

Student Workflow Instructions
  1. Select an Issue: Pick an unassigned defect below (Issue #01 to #10).
  2. Raise on GitHub: File a formal GitHub Issue (e.g. [Bug]: Issue #01 - Kudos sort order inverted) and assign it to a team member.
  3. Branch & Fix: Run git checkout -b fix/issue-XX-description, investigate the source code, and implement the resolution.
  4. Verify & Push: Test locally in your browser, commit with conventional commit format, and push your branch upstream.
  5. Open Pull Request: Open a PR referencing Fixes #<issue-num> to trigger the automated CI pipeline!
